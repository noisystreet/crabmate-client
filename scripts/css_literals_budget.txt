# CSS 字面量预算（门禁：scripts/check-css-literals.sh）
#
# 扫描范围：frontend/styles/*.css，排除 tokens.css（token 定义处）；themes/*.css 不扫描（本就定义颜色）。
#
# 格式：<相对路径>  font-size=<n>  color=<n>  border-radius=<n>   # <理由 / 清理计划>
#   - 缺 '# 理由' / 重复登记 / 字段缺失：门禁报格式错误；
#   - 实际值必须等于预算值：写多写少都 fail（清理后不同步下调，条目就成了「隐性豁免」）；
#   - 未登记的文件预算视为 0；三项均为 0 的条目、或文件已不存在的条目，报预算失效，须删除。
#
# 目标是把存量逐文件清到 0，清理一处就下调一处预算。
# 当前进度：font-size 已全量清到 0（Phase 1a，字号统一走 tokens.css 的 --text-* 档）；
# 颜色已清 alert 五色、--danger 兼容别名（Phase 1b，语义色归一）、inset 高光 / 强调底前景
# （Phase 1c，走 --inset-highlight / --on-accent）与遮罩 / 浮层阴影
# （Phase 1d，走 --scrim-bg / --modal-backdrop-bg / --shadow-menu / --shadow-media / --shadow-knob），
# 故仅剩壳层专用的固定红底白字不做 token 化（它的语义不随主题）。
# border-radius 为 Phase 2 新增维度：可归入 --radius-* 阶梯的 8 处已收敛，
# 余下是 var(--radius-*, N) 兜底（token 恒有定义、兜底不生效）与阶梯外的语义圆角（发丝 / 圆形 / 气泡 / 随字号）。
